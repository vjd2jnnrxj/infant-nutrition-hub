# 百色市人民医院青年文明号集体开展“保护母亲河▪扬雷锋精神”志愿服务活动

> 更新时间：2026-09-16 (UTC+8)

点击上方"蓝字"关注我们吧！

**助力文明城市创建**

每年3月9日是保护母亲河日，为发扬雷锋精神，充分发挥共青团后备军和生力军作用，营造整洁、优美的城市环境，弘扬“奉献、友爱、互助、进步”的志愿服务精神，百色市人民医院团委组织青年文明号集体开展“保护母亲河▪扬雷锋精神”志愿服务活动，主要围绕右江开展巡河护河活动，清理河岸边上的生活垃圾、落叶及绿化带中的塑料杂物等。

志愿者整装待发

当天上午9时，志愿者们在门诊大楼集合，带上清理工具统一出发步行至大码头河段，开始进行清理河岸边上的生活垃圾、落叶及绿化带中的塑料杂物，一路步行清理至中山桥河段。

志愿者清理河道

此次活动，不仅改善了河岸沿线的环境，志愿者们还以实际行动倡导环保、文明的生活理念，引领广大群众关注目前水资源管理与保护、水环境治理、水污染防治、水生态修复等问题。提高了群众的文明意识，带动更多的人参与其中，为助力创建全国文明城市贡献一份力量。

**青年文明号介绍**

青年文明号（英文名称为:Youth Model Unit Award）是指在生产、经营、管理和服务中创建并经过活动组织管理部门认定的，体现高度职业文明、创造一流工作业绩的青年集体。

创建“青年文明号”活动意义：以促进职业青年发展和职业文明进步为根本功能，以各行各业一线青年集体为创建主体，以服务一流、管理一流、人才一流、文化一流、效益一流等为争创目标，以实施科学管理、人本管理、自我管理和各类岗位创新创效创优活动为基本手段，在实践中培育政治素质好、职业道德好、职业技能好、工作作风好、岗位业绩好的五好先进集体和培养青年人才的群众性创建活动。

百色市人民医院目前拥有2个省级青年文明号集体,分别为急救医学中心青年文明号集体、感染疾病科一区青年文明号集体；2个市级青年文明号集体，分别为骨科青年文明号集体、血管外科青年文明号集体；2个院级青年文明号集体，分别为儿童医院青年文明号集体、检验科青年文明号集体。
